# QuasarApp Group Website

A modern, multi-language website for the QuasarApp organization showcasing our projects and services.

## Features

- ✨ **Multi-language Support** - Available in English, Russian, German, and Spanish
- 🎨 **Material + Sci-Fi Design** - Futuristic UI with glowing effects and modern aesthetics
- 🌊 **Parallax Animations** - Smooth scrolling and 3D effects
- 📱 **Responsive Design** - Works perfectly on all devices
- 🚀 **Fast & Lightweight** - Pure HTML, CSS, and JavaScript

## Projects Showcased

- **QuasarApp** - Cross-platform desktop application framework
- **Platforms** - Platform abstraction layer
- **OpenSimplex2** - Fast noise implementation
- **Quasar Framework** - Full-stack web framework

## Technologies Used

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript (ES6+)
- Google Fonts (Roboto)
- Font Awesome Icons

## Deployment

This repository is configured for GitHub Pages deployment. To deploy:

1. Push to GitHub
2. Go to Settings > Pages
3. Select the `main` branch as the source
4. Your site will be available at `https://quasarapp.github.io/site/`

## Development

To test locally:

```bash
cd /path/to/site
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
